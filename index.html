SQL First

Plain SQL files. No DSL, no XML, no surprises. You write SQL, dbsh tracks and applies it.

🗄️

Multi-Database

One tool, four engines. PostgreSQL, SQL Server, MySQL, and SQLite. Switch providers without changing workflow.

🔒

Safe by Design

Distributed locks, approval gates, deployment windows, and audit trails. Production-grade from day one.

⚡

CI/CD Ready

Every command supports --json output and deterministic exit codes. Plug it into any pipeline.

📴

Works Offline

Validate, plan, and scaffold without a database connection. Use --in-memory for local dev.

🔍

Checksum Integrity

SHA-256 checksums detect when applied scripts are edited. No silent drift in production.
